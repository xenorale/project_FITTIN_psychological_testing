# Кабинет HR — СМИЛ / MMPI

Фронтенд личного кабинета рекрутера для платформы психологического тестирования (практика FITTIN, лето 2026).

Пока бэкенда нет — все данные замоканы (`src/mock.ts`).

## Что внутри

- Вход HR (мок-авторизация, токен в localStorage)
- Дашборд: статистика, список кандидатов, статусы, поиск и фильтры
- Создание именной ссылки-приглашения
- Карточка результата кандидата: профиль СМИЛ (Recharts), шкалы достоверности L/F/K, таблица T-баллов, текстовая интерпретация
- Экспорт карточки в PDF (через печать браузера)

## Стек

React + TypeScript + Vite, Recharts, react-router-dom.

## Запуск

```bash
npm install
npm run dev
```

Откроется на http://localhost:5173

Демо-вход: любая почта и пароль.

## Сборка

```bash
npm run build
```
