# Бэкенд СМИЛ / MMPI — FITTIN

Backend для платформы психологического тестирования кандидатов (практика FITTIN, лето 2026).
Закрывает контракт фронтенда из ветки `Frontend_1`.

## Стек

- Python 3.11, FastAPI, Pydantic
- PostgreSQL, SQLAlchemy, Alembic
- JWT-авторизация HR (без внешних identity-провайдеров)
- WeasyPrint для PDF-карточки результата
- Docker Compose (backend + postgres)

## Запуск

```bash
docker compose up --build
```

Backend поднимется на `http://localhost:8000`, миграции накатываются автоматически при старте контейнера.

Наполнить базу тестовыми кандидатами (как в моках фронта):

```bash
docker compose exec backend python -m app.seed
```

Демо-вход HR: `hr@fittin.ru` / `fittin2026`.

## Эндпоинты

- `POST /api/auth/login` — вход HR, возвращает JWT
- `POST /api/invites` — создать именное приглашение (нужен токен HR)
- `GET /api/invites/{token}` — данные приглашения и утверждения теста в случайном порядке
- `POST /api/invites/{token}/submit` — приём ответов, запуск скоринга
- `GET /api/candidates` — список кандидатов (нужен токен HR)
- `GET /api/candidates/{id}` — карточка результата: профиль, сырые баллы, валидность, интерпретация
- `GET /api/candidates/{id}/pdf` — PDF-карточка результата

## Про scoring engine

Ключи шкал СМИЛ/MMPI (L, F, K + 13 клинических шкал), K-коррекция и перевод сырых баллов
в T-баллы реализованы в `app/scoring`. Банк утверждений и нормативные коэффициенты — свои,
собраны по структуре методики; итоговую сверку T-баллов с эталонным тестом
(psytests.org) ещё предстоит прогнать на контрольных наборах ответов — это отдельный этап
по плану практики, а не часть бэкенд-разработки.
