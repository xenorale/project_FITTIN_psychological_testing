# Платформа для психологического тестирования кандидатов (СМИЛ / MMPI)

Веб-приложение для автоматизации процесса психологического тестирования кандидатов при приеме на работу. Проект состоит из двух ключевых частей: модуля прохождения тестов для кандидатов и личного кабинета HR-специалиста для анализа результатов.

Проект разработан в рамках летней практики в компании FITTIN (2026 год).

---

## Основной функционал

### Кабинет HR-специалиста:
* **Панель управления (Dashboard):** Отображение общей статистики по тестированиям, списка кандидатов с фильтрацией, поиском и статусами прохождения.
* **Система инвайтов:** Генерация уникальных персонализированных ссылок для прохождения теста кандидатами под конкретные вакансии.
* **Карточка кандидата:** Детальный разбор результатов, включая расчет сырых баллов и перевод их в стандартизированные Т-баллы.
* **Визуализация профиля СМИЛ:** Построение адаптивных графиков на основе результатов. Для незавершенных тестов выводится линейный график тренда, для полностью пройденных - детальная столбчатая диаграмма.
* **Анализ достоверности:** Автоматическая оценка искренности ответов по трем шкалам достоверности (L, F, K) с цветовой индикацией отклонений от нормы.
* **Текстовая интерпретация:** Вывод автоматического заключения по ведущим клиническим шкалам.
* **Экспорт отчета:** Подготовка адаптивной печатной формы карточки результата и сохранение в формат PDF средствами браузера.

### Модуль кандидата:
* Авторизация по уникальному токену из приглашения.
* Интуитивный интерфейс для поочередного ответа на вопросы теста с индикацией прогресса заполнения.
* Сохранение промежуточных ответов и отправка результатов на сервер для последующего обсчета.

## Стек технологий

### Frontend:
* React (компонентный подход)
* TypeScript (строгая типизация данных)
* Vite (сборщик проекта)
* Recharts (визуализация графиков и диаграмм)
* React Router v6 (навигация внутри приложения)
* TanStack Query / React Query (асинхронные запросы и кэширование данных)

### Backend & База данных:
* Python 3.11 (FastAPI)
* PostgreSQL (хранение данных кандидатов, вопросов и результатов)
* SQLAlchemy (ORM для работы с базой данных)
* Alembic (управление миграциями БД)
* Docker / Docker Compose (контейнеризация приложения)

## Как запустить проект локально

Для полноценного запуска проекта вам понадобятся установленные Node.js и Docker Desktop.

### 1. Запуск бэкенда и базы данных
Все серверные компоненты упакованы в Docker, поэтому запускаются одной командой.
* Откройте терминал в корневой папке проекта и выполните сборку:
  ```bash
  docker compose up --build
  ```
* После того как сервер запустится (в логах появится строка Uvicorn running on http://0.0.0.0:8000), откройте второе окно терминала и наполните пустую базу данных тестовыми кандидатами и вопросами:
  ```bash
  docker compose exec backend python -m app.seed
  ```

### 2. Запуск фронтенда
* Откройте отдельный терминал в корневой папке проекта.
* Установите необходимые пакеты:
  ```bash
  npm install
  ```
* Запустите локальный сервер разработки Vite:
  ```bash
  npm run dev
  ```
* Перейдите в браузере по адресу, который выдаст консоль (по умолчанию это http://localhost:5173).
